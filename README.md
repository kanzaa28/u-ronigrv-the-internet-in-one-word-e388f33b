**feral** — one word for the whole internet. Wild, untamed, no rules, no owner:
every corner of it raised itself. Five letters, one beat, no explanation needed.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry word, byte-exact and with no trailing newline, to
`/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR` for local
runs). Verified: two runs produce byte-identical output — 5 bytes, sha256
`db013e753c12a7482c53d0abc72171a25d6d2b79bf7ac75cddcccb5fe4caee32`.
